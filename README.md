# C++ Search Engine

This is a simple search engine built in C++ using file handling that allows users to search for keywords in stored text data and display matching results.

##mFeatures
Store and manage text data
Search keywords or phrases
Display relevant results

The program stores input data and searches through it when a query is entered, returning matching results using basic data structures.

## Purpose

To understand the basic working of search engines, including data storage and searching techniques.
